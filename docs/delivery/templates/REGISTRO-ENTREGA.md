## Control y capacitación

- [ ] El cliente conserva un propietario y operador propios comprobados.
- [ ] La custodia de secretos y recuperación pertenece al cliente por referencia protegida.
- [ ] Usuarios y operadores ejecutan ejercicios sobre la versión exacta.
- [ ] Importación/exportación concilian identidades, relaciones y valores.
- [ ] Backup y restauración completos tienen recibos observados.
- [ ] MIT y avisos aplicables forman parte del paquete, no sólo un enlace.
- [ ] Soporte dispone de autorización temporal y mínimo acceso.
- [ ] Revocación de sesiones, claves y demás acceso produce denegaciones comprobadas.
- [ ] La instalación funciona para el cliente tras retirar soporte.
- [ ] El expediente declara todos los pendientes y límites de operación.
- [ ] La instalación y datos reales tienen autoridad independiente de pruebas.
- [ ] El acta contiene una decisión real del representante autorizado.
